Settings

GitHub token

Rule changes and game requests are sent by committing small files to your repo (FatPimp420/AutoGPT), so the app needs a GitHub token with write access to that repo's contents. It is stored only on this device.

Create one at github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens: select only the AutoGPT repository, and under Repository permissions set Contents: Read and write. (A classic token with the repo scope also works.)

About

Self-play PPO training on the GAIGResearch/Tribes engine. Training runs in a Claude Code cloud container; this app reads its published data from GitHub Pages and writes commands back to the repo. If the curves stop updating for a long time, the training container has likely been recycled — ask Claude to restart it; weights and history survive.
